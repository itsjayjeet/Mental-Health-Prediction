 Mental Health Prediction using Machine Learning

📌 Project Overview

Mental Health Prediction is a machine learning project designed to predict students' mental health scores based on various academic, lifestyle, and social media-related factors.

The project explores how factors such as study hours, sleep duration, stress levels, social media usage, and other student-related attributes can be used to build a predictive machine learning model.

This project demonstrates the complete machine learning workflow, from data preprocessing and exploratory data analysis to model training and deployment using FastAPI.

🎯 Objectives

* Analyze factors that may influence students' mental health.
* Perform data cleaning and exploratory data analysis.
* Preprocess numerical and categorical features.
* Build a machine learning model to predict mental health scores.
* Deploy the trained model using FastAPI.
* Develop a simple interface for making predictions.

 🛠️ Technologies Used
-Programming Language:** Python
-Libraries:** Pandas, NumPy, Scikit-learn
-Machine Learning:-Regression, Pipelines, ColumnTransformer
-Backend:-FastAPI
-Frontend:- HTML, CSS, JavaScript
Development Environment:-Jupyter Notebook, VS Code

 🔍 Machine Learning Workflow

1. Data Collection:** Load the student mental health dataset.
2. Data Preprocessing:** Handle missing values and prepare numerical and categorical features.
3. Exploratory Data Analysis:** Understand relationships between student lifestyle factors and mental health scores.
4. Feature Engineering:** Prepare relevant features for model training.
5. Model Training:** Train a machine learning regression model.
6. Model Evaluation:** Evaluate the model using suitable regression metrics.
7. Deployment:** Integrate the trained model with a FastAPI application.

 📊 Key Features

- Student mental health score prediction.
- Data preprocessing using Scikit-learn pipelines.
- Handling numerical and categorical features using ColumnTransformer.
- Machine learning model integration with FastAPI.
- Interactive prediction interface.
